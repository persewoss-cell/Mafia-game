# 🕵️ 마피아 게임 (Firebase 실시간 버전)

코딩을 처음 접하는 분도 따라 할 수 있도록, 설치 없이 **Firebase 콘솔에서 클릭 몇 번**으로 실행할 수 있게 만들었습니다.

## 1. 화면 구성

- `index.html` : 전체 화면 구조
- `style.css` : 디자인 (아이들과 태블릿으로 쓰기 좋게 큼직한 버튼/글씨)
- `app.js` : 게임 로직 (Firestore와 실시간으로 데이터를 주고받는 부분)
- `firebase-config.js` : **여기에 본인 Firebase 프로젝트 키를 넣어야 합니다.**
- `firestore.rules` : Firestore 보안 규칙 (콘솔에 붙여넣기용)

## 2. Firebase 프로젝트 설정 (최초 1회)

1. https://console.firebase.google.com 에서 새 프로젝트를 만듭니다.
2. 왼쪽 메뉴 **빌드 > Firestore Database** 로 들어가 **데이터베이스 만들기**를 클릭합니다.
   - 위치는 가까운 지역(예: asia-northeast3)을 선택하고, 테스트 모드로 시작해도 됩니다.
3. **규칙(Rules)** 탭으로 이동해서 이 저장소의 `firestore.rules` 내용을 복사해 붙여넣고 **게시**합니다.
4. 프로젝트 설정(⚙️ 아이콘) > **일반** 탭 맨 아래 "내 앱" 에서 `</>` (웹 앱) 아이콘을 눌러 앱을 등록합니다.
5. 발급된 `firebaseConfig` 값을 복사해서, 이 저장소의 `firebase-config.js` 파일에 그대로 붙여넣습니다.

```js
const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
```

## 3. 실행 방법

Firestore는 `file://` 로 직접 여는 것보다 웹 서버를 통해 여는 것이 안정적입니다. 가장 쉬운 방법 두 가지:

### 방법 A. Firebase Hosting (추천, 무료)

```bash
npm install -g firebase-tools
firebase login
firebase init hosting   # public 디렉터리를 이 폴더(index.html이 있는 위치)로 지정
firebase deploy
```

배포 후 나오는 URL을 태블릿에서 열면 됩니다.

### 방법 B. 로컬에서 바로 테스트

```bash
# 이 폴더에서
python3 -m http.server 8000
```

그 다음 브라우저에서 `http://localhost:8000` 접속. 같은 와이파이의 태블릿에서는 PC의 IP 주소로 접속하면 됩니다 (예: `http://192.168.0.5:8000`).

## 4. 게임 진행 방법

1. **관리자(진행자)**: "게임 만들기" → 참가 인원 수 입력 → 4자리 코드 생성
2. **참가자들**: 각자의 기기(태블릿/휴대폰)에서 "게임 참가하기" → 코드 + 이름 입력
3. 인원이 다 모이면 관리자가 "게임 시작하기"를 누르면 역할이 자동으로 무작위 배정됩니다.
   - 마피아 = 전체 인원 ÷ 3 (반올림)
   - 의사 = (전체 − 마피아) ÷ 5 (반올림)
   - 경찰 = 의사 ÷ 2 (반올림, 인원이 적으면 0명일 수 있음)
   - 시민 = 나머지
4. 각자의 화면에는 본인의 역할만 보이고, 마피아끼리는 서로의 명단을 볼 수 있습니다.
5. **낮**: 참가자들이 의심되는 사람에게 투표 → 전원이 투표하면 자동으로 결과 공개
   - 동률이면 그 인원끼리 자동으로 재투표하며, 최다 득표자가 1명이 될 때까지 반복됩니다.
6. **밤**: 마피아들이 제거할 대상 투표(동률 시 재투표) → 의사가 살릴 사람 선택 → 경찰이 조사할 사람 선택 → 결과 공개
   - 의사가 2명이면 서로 다른 2명까지 구할 수 있고, 같은 사람을 선택하면 1명만 구해집니다. 단, **의사는 경찰을 살릴 수 없습니다** — 경찰을 선택해도 마피아의 표적이었다면 그대로 사망합니다.
   - 경찰은 산 사람 중 한 명을 조사해 그 사람이 **마피아인지 아닌지만** 알아냅니다 (정확한 직업까지는 알 수 없음). 결과는 조사한 경찰 본인에게만 보이며, **50% 확률로 조사에 실패**할 수 있습니다.
   - 마피아 투표 후에는 10초 카운트다운 뒤 의사 선택으로 넘어가고, 의사 선택이 끝나면 대기 없이 바로 경찰 조사로 넘어갑니다. 경찰 전원이 조사를 마치면 결과를 읽을 7초를 준 뒤 다음 단계로 넘어갑니다.
7. 마피아가 모두 탈락하면 **시민 승리**, 생존한 시민+의사+경찰 수가 마피아 수 이하가 되면 **마피아 승리**로 게임이 자동 종료됩니다.
8. 관리자는 화면 우측 상단의 "게임 종료" 버튼으로 게임을 언제든 강제 종료할 수 있습니다. 누르면 모든 참가자가 자동으로 처음 화면으로 돌아갑니다.

## 5. 알아두면 좋은 점 (베타 안내)

- 이 게임은 로그인 기능이 없는 **간단한 코드 입장 방식**이라, Firestore 보안 규칙을 열어두었습니다. 외부에 공개하지 말고, 같이 노는 사람들끼리만 코드를 공유하세요.
- 새로고침해도 자동으로 이전 화면(대기실/게임 중)으로 복귀합니다.
- 한 게임이 끝나면 관리자가 "새 게임 만들기"를 눌러 새로운 코드로 다음 라운드를 시작할 수 있습니다.
